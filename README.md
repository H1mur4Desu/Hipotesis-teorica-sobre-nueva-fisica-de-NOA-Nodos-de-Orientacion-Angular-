## 🌌 Sobre el Proyecto
Este repositorio contiene el código fuente y la base teórica del experimento diseñado para aislar y medir el parámetro de acoplamiento débil ($\gamma_{12}$) postulado en la **Cosmología Informacional Unificada**. 

El objetivo es demostrar matemáticamente cómo la consciencia (el "Foco Explorador") interactúa con el Deep Hilbert Space (DHS), produciendo una extorsión probabilística medible sobre un sistema cuántico aleatorio puro.

## 🛠️ Herramientas y Hardware
El código escrito en Python conecta vía API con un Láser Cuántico (QRNG) en la Universidad Nacional de Australia, midiendo fluctuaciones del vacío cuántico en tiempo real para generar un entorno perfecto de 50/50.

## 📂 Contenido del Repositorio
* `app_foco.py`: Interfaz gráfica (GUI) para la recolección de datos del experimento humano (Foco Explorador).
* `bot_control.py`: Script automatizado para establecer el Grupo de Control científico (aleatoriedad sin consciencia).
* `tesis_NOA.tex`: Documento fundacional escrito en LaTeX con el marco matemático y cosmológico completo.
